# 图片资源清单

实际机器可检查的清单位于 `docs/assets/asset-manifest.json`，本文件面向维护者解释分类和预算。

## 分类

- `runtime-critical`：启动、图标和首屏必须资源。
- `runtime-feature`：功能使用的图片，例如塔罗牌面和背景。
- `user-content`：用户头像、聊天图片和生成内容。
- `source-only`：概念图、原始生成图和设计素材，不进入运行时加载。

## 当前重点

- 塔罗牌面保持 `768x1152`，优先保证线条、文字和暗部细节。
- 单张塔罗牌超过 `350 KB` 会警告，超过 `500 KB` 会阻止检查。
- 图片不通过极低质量压缩解决速度问题，优先使用正确显示尺寸、现代格式和按需加载。
- `public/tarot/concepts` 是原始概念图归档，不能加入预加载清单。

## 检查

```powershell
npm run check:assets
```

AI 替换图片时必须报告原始尺寸、运行时尺寸、文件体积、格式、是否预加载和本地验收地址。
