# 塔罗阶段时间线

时间以当前代码中的动画契约为准；修改时必须同步代码和本表。

| 阶段 | 进入条件 | 用户动作 | 结束条件 |
| --- | --- | --- | --- |
| `question` | 打开塔罗 | 选择问题或输入内容 | 确认问题 |
| `spread` | 问题已确认 | 选择牌阵 | 牌阵确认 |
| `shuffle` | 牌阵已确认 | 按住完成洗牌 | 洗牌动画完成 |
| `cut` | 洗牌完成 | 按住完成切牌 | 牌堆落下 |
| `fan` | 切牌完成 | 选择规定数量牌 | 选牌完成 |
| `reveal` | 选牌完成 | 翻开卡牌 | 所有目标牌翻开 |
| `reading` | 翻牌完成 | 阅读、分享、查看历史 | 重新开始或关闭 |

具体毫秒数由 `src/games/tarot/tarotAnimation.ts` 维护。不要用多个未命名 `setTimeout` 覆盖该契约。
