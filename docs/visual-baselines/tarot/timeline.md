# 塔罗阶段时间线

时间以当前代码中的动画契约为准；修改时必须同步代码和本表。

| 阶段 | 进入条件 | 用户动作 | 结束条件 |
| --- | --- | --- | --- |
| `question` | 打开塔罗 | 选择问题或输入内容 | 确认问题 |
| `spread` | 问题已确认 | 选择牌阵 | 牌阵确认 |
| `shuffle` | 牌阵已确认 | 按住完成洗牌 | 洗牌动画完成 |
| `cut` | 洗牌完成 | 按住完成切牌 | 牌堆落下 |
| `fan` | 切牌完成 | 选择规定数量牌 | 选牌完成 |
| `reveal` | 选牌完成 | 翻开卡牌 | 所有目标牌翻开 |
| `reading` | 翻牌完成 | 阅读、分享、查看历史 | 重新开始或关闭 |

具体毫秒数由 `src/games/tarot/tarotAnimation.ts` 维护。不要用多个未命名 `setTimeout` 覆盖该契约。

### `fan` 选牌飞行

- 点击后使用独立视觉副本从扇面卡牌的实际位置飞向对应已选槽位。
- 时长为 `900ms`，缓动为 `cubic-bezier(.18, .82, .26, 1)`。
- 起点保留原卡尺寸与扇形角度，中段轻抬并沿弧线移动，终点与槽位中心和尺寸一致。
- 原卡只淡出，不改变扇形布局；落位完成后再提交选牌完成事件。
- `0–140ms` 使用边缘流光蓄能，并出现紫色方向拖尾。
- 飞行副本只显示卡牌本体，不创建拖尾、粒子、扫光、光环或落位爆发。
- 前 `50%` 时间完成约 `82%` 位移，随后持续减速，在终帧精准对齐目标槽位。
- 飞行期间不改变整体亮度，仅平滑过渡边框与阴影以保证副本和真实已选牌连续交接。
- 副本终帧的边框、阴影、亮度、位置和尺寸与真实已选牌完全一致；真实已选牌不再播放额外亮度动画。
- “已选 a/b”上方不显示装饰性小牌堆。
- 已选牌整行略微下移，但上下外边距总和保持不变，不挤压扇形牌区域。
- 上方已选牌尺寸大于下方扇形牌；三张模式扩大牌间距，五张模式在 `380px` 以下缩小牌面并保留正间距，禁止相邻牌重叠。
- reduced motion 直接完成逻辑结果，不创建飞行副本。
