# 塔罗人工验收标准

## 流程

- [ ] 阶段顺序正确。
- [ ] 快速点击或重复按压不会跳阶段。
- [ ] 动画结束后才解锁下一操作。
- [ ] 重新开始回到干净初始状态。

## 视觉

- [ ] `390x844` 无横向滚动。
- [ ] `1280x800` 布局居中且比例正常。
- [ ] 牌背、背景和牌面没有闪烁。
- [ ] 卡牌层级、阴影和旋转没有穿帮。

## 无障碍与异常

- [ ] reduced-motion 能完成全部流程。
- [ ] 图片加载失败有可理解反馈。
- [ ] 浏览器控制台无应用错误。

## 回归

- [ ] 历史记录正常。
- [ ] 分享正常。
- [ ] 关闭再打开不继承错误动画锁。
