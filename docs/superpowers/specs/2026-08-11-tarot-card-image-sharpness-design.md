# 塔罗卡牌图像清晰度设计

**日期：** 2026-08-11
**目标：** 让所有塔罗牌背与牌面在静态、缩放、旋转和动画状态中使用一致的清晰图像渲染策略，减少小尺寸与复合变换带来的软化感。

## 背景

牌背原图为 `768x1152`，资源分辨率充足。清晰度差异来自卡牌在小尺寸、旋转、半像素布局和 GPU 合成层中的重复重采样，而不是资源本身模糊。扇形牌和飞行副本是最显著的场景，但洗牌、切牌、翻牌和阅读牌面也应遵循同一图层规则。

## 方案

1. 建立单一 CSS 图像质量契约，覆盖所有牌背背景与正面 `<img>`。
2. 去除扇形静态牌面不必要的子图层预合成提示；变换只保留在卡牌外壳，视觉内容不再额外声明 `will-change`。
3. 将扇形卡片的可控纵向偏移量量化到整像素，避免静态展示落在半像素上。
4. 保留飞行副本的外壳级 `will-change: transform, opacity`，因为它实际执行 Web Animations 位移；其图像质量规则与其余卡牌一致。
5. 不更换资源、不修改阶段状态机、动画时长、牌面尺寸设计、交互锁或 reduced-motion 流程。

## 覆盖范围

- 洗牌：牌背堆叠。
- 牌阵预览：小尺寸旋转牌背。
- 切牌：两个牌堆的顶部牌背。
- 扇形选牌：静态牌背与飞行副本。
- 翻牌：牌背、正面牌图、逆位和裁切牌图。
- 阅读：正面牌图。

## 验收

- 所有卡牌图像选择器应用统一的高质量图像渲染规则。
- 扇形静态牌不再为内部视觉元素创建 `will-change` 合成层，纵向扇形偏移为整像素。
- `fan` 飞行仍为 `900ms`、保持原有路径与终帧对齐。
- `390x844` 与 `1280x800` 下，牌背和牌面在洗牌、切牌、扇形、飞行、翻牌和阅读阶段没有异常软化、闪白或布局回归。
- reduced-motion、快速输入与浏览器控制台维持正常。
