# 塔罗标准桌面切牌动画设计

## 目标

将当前切牌阶段重做为真实、流畅且具有明确三维层次的标准桌面切牌：

1. 上半叠牌从牌堆中抬起。
2. 上半叠沿右侧连续弧线越过下半叠。
3. 原下半叠明显上移，成为新的顶部牌叠。
4. 原上半叠回到中心并落入底层。

用户应始终能追踪两叠牌的身份，并清楚看出原上半叠被放到了原下半叠下面。

## 已确认视觉方案

采用可视化分镜 V7“上移落点版”：

- 保留较宽的标准桌面切牌弧线。
- 整组动画位于切牌区域中央，不向画面底部偏移。
- 移动牌最终落点比旧方案更高，垂直坐标约为 `-5px`。
- 原下半叠从偏下位置明显上升到约 `-13px`，成为新的顶部。
- 原上半叠通过更深的 Z 轴、较低亮度和遮挡关系成为新的底部，而不是依靠较大的屏幕纵向间距表达层级。

## 根因与技术方向

旧切牌动画主要通过多段 CSS 关键帧和多个嵌套动画拼接动作。关键帧交界处的速度变化以及各图层时间轴差异，会使过程产生停顿、折角或类似卡帧的观感。

新版使用一个连续动画进度驱动所有视觉状态：

- 使用 `requestAnimationFrame` 提供统一主时钟。
- 上半叠、下半叠和投影共享同一个标准化进度。
- 使用连续平滑函数计算位移，不拼接相互独立的 CSS 动画。
- CSS 只负责三维场景、牌面外观、厚度和静态层级；运行时只更新 `transform`、`filter`、`opacity` 和层级。
- 不在动画过程中修改布局尺寸、边距或定位属性。

## 动作时间轴

单次切牌时长约为 `1350ms`。

### 1. 取起

- 原上半叠向上移动，并向镜头方向增加 Z 轴深度。
- 最大垂直抬升约 `58px`。
- 最大前向深度约 `88px`。
- 轻微 `rotateX` 和 `rotateZ` 展示牌边厚度。
- 投影同步缩小、变淡并向右移动。

### 2. 右侧弧线

- 桌面端最大横向距离约 `112px`。
- 移动端最大横向距离约 `76px`。
- 横向移动、抬升与下降由同一进度连续计算。
- 轨迹不能出现中途静止、直角转折或速度突变。

### 3. 下半叠升顶

- 当移动牌越过动作中段后，原下半叠开始持续上移。
- 垂直坐标从约 `22px` 移动到约 `-13px`。
- Z 轴从约 `-20px` 移动到约 `20px`。
- 同时轻微提亮并短暂倾斜，使其成为新的视觉顶部。

### 4. 上半叠归底

- 原上半叠沿弧线返回中心。
- 最终垂直坐标约为 `-5px`，不能明显低于新的顶部牌叠。
- 最终 Z 轴约为 `-126px`，并适度压暗。
- 层级在越过下半叠之后切换，使其明确进入底层。
- 最终状态需要保持短暂停留，方便用户确认切牌结果。

## 三维表现

切牌按钮提供约 `1050px` 至 `1100px` 的透视距离，并启用 `transform-style: preserve-3d`。

每半叠牌使用额外图层或伪元素表现：

- 浅色纸张边缘。
- 深色底层牌边。
- 不同深度下的亮度差异。
- 随牌堆高度变化的接触阴影。

最终状态中：

- 新顶部牌叠更亮、更靠近镜头。
- 新底部牌叠更暗、更深入场景。
- 两叠在屏幕纵向上保持紧邻，主要依靠 Z 轴和遮挡表达上下关系。

## 组件与状态

继续使用现有 `TarotCutStage` 和塔罗流程状态：

- `cutting` 阻止重复点击。
- `cutCount` 只在完整动画结束后增加。
- 至少完成一次切牌后才能进入选牌。
- 奇偶次切牌继续交替两叠牌的身份。

`TarotCutStage` 内部负责动画帧：

- 开始切牌时记录起始时间。
- 每一帧计算统一进度并更新两个牌叠和投影的视觉变量。
- 达到动画时长后停止帧循环并通知流程完成切牌。
- 组件卸载、切换阶段或开始新动画时取消旧帧，避免残留更新。

完成回调应基于当前动画令牌或等价保护，防止过期动画结束事件修改新状态。

## 无障碍与降级

- `prefers-reduced-motion: reduce` 下不运行逐帧移动，直接完成一次切牌状态变化。
- 切牌按钮在运行期间保持禁用。
- 两叠牌和装饰层为纯视觉内容，不增加多余的可聚焦元素。
- 动画仅使用合成友好的属性，避免在移动端触发布局重排。

## 测试

### 状态测试

- 切牌开始后锁定按钮。
- 完成回调只接受当前动画。
- 单次完成只增加一次 `cutCount`。
- 连续切牌正确交替上下牌叠身份。
- reduced-motion 立即完成状态变化。

### 动画逻辑测试

将轨迹计算提取为纯函数，验证：

- 起点与静止状态一致。
- 上半叠横向最大位移符合桌面端和移动端约束。
- 上半叠最终 Y 坐标约为 `-5px`。
- 上半叠最终 Z 坐标处于底层。
- 下半叠最终 Y 坐标约为 `-13px`。
- 下半叠最终 Z 坐标处于顶部。
- 全时间轴输出连续，不存在阶段间位置跳变。

### 样式测试

- 场景保留透视和 `preserve-3d`。
- 两叠牌具有可见厚度。
- 动画只更新合成友好的视觉属性。
- 移动端使用较短横向距离。

### 验收检查

- 桌面宽度下动画整体居中，无裁切和底部偏移。
- 移动端牌叠不超出视口。
- 右移、下降和回中全程流畅，无卡帧感。
- 下半叠上移幅度明显。
- 原上半叠最终位置紧邻新顶部，但在三维层级上清楚位于其下方。

## 修改范围

预计修改：

- `src/games/tarot/TarotCutStage.tsx`
- 新增或扩展切牌轨迹计算模块
- `src/games/tarot/tarotRitual.css`
- 相关塔罗组件、状态和样式测试

不修改：

- 洗牌、扇形选牌、翻牌和解读动画。
- 牌库随机规则。
- 塔罗牌面资源。
- 其他应用页面样式。
