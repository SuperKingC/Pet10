# 小多利重要记忆与提醒任务设计

## 1. 目标

本次同时完成两个相关能力：

1. 让重要记忆稳定保存、立即同步并在后续回答中优先生效。
2. 让用户通过自然语言直接创建单次、每日和每周提醒，不需要二次确认。

## 2. 非目标

- 不执行购买、转账、删除文件、操作外部账号等高风险动作。
- 不把提醒扩展为任意代码或外部工具执行器。
- 不修改聊天页面布局和视觉样式。
- 不实现复杂日历同步。
- 不支持按月、工作日或任意 Cron 表达式。

## 3. 重要记忆

### 3.1 明确记忆

用户使用以下表达时立即保存：

- `记住我不吃香菜`
- `记住以后叫我小陈`
- `我的生日是 5 月 20 日`
- `我喜欢摄影`
- `我住在上海`

明确记忆不经过随机概率，也不受自动提取冷却影响。保存成功后，小多利的当前回答可以自然表示已经记住。

### 3.2 自动记忆

普通聊天结束后，AI 可以提取一条长期事实。自动提取：

- 不再使用 50% 随机跳过。
- 同一房间只允许一个提取任务并发运行。
- 只有成功写入后才更新冷却时间。
- 重复内容不新增。
- 新内容与旧记忆属于同一类别时允许更新，而不是无限堆积。

### 3.3 记忆结构

记忆增加：

```ts
type MemoryCategory = 'identity' | 'preference' | 'habit' | 'plan' | 'relationship' | 'other'
type MemorySource = 'explicit' | 'inferred'

interface PetMemory {
  category: MemoryCategory
  importance: 1 | 2 | 3
  source: MemorySource
  updatedAt: Date
}
```

明确记忆默认 `importance=3`，自动记忆默认 `importance=2`。

### 3.4 注入规则

回答时最多注入 15 条记忆，排序为：

1. 明确记忆优先。
2. 重要程度高优先。
3. 最近更新优先。

不再把全部 60 条记忆无差别加入提示词。

### 3.5 实时同步

保存成功后发送：

```text
memory.created
```

删除继续使用：

```text
memory.deleted
```

前端房间运行时收到创建事件后立即更新记忆列表。

## 4. 提醒任务

### 4.1 支持表达

- `30 分钟后提醒我关火`
- `明天早上 8 点提醒我带伞`
- `每天晚上 11 点提醒我睡觉`
- `每周一早上 9 点提醒我开会`

解析成功后直接创建，不要求用户确认。

### 4.2 时间规则

- 默认时区为服务端配置的 `Asia/Shanghai`。
- 缺少具体时间且无法可靠推断时，不创建任务，直接追问具体时间。
- 过去时间不创建。
- 单次任务执行后标记完成。
- 每日和每周任务执行后计算下一次执行时间。

### 4.3 数据结构

```ts
interface PetTask {
  id: string
  roomId: string
  userId: string
  instruction: string
  scheduleType: 'once' | 'daily' | 'weekly'
  runAt: Date
  weekday?: number
  hour: number
  minute: number
  timezone: string
  status: 'pending' | 'completed' | 'cancelled' | 'failed'
  nextRunAt: Date
  createdAt: Date
  updatedAt: Date
}
```

### 4.4 执行方式

服务启动时创建提醒调度器，每分钟查询到期任务：

1. 创建一条小多利聊天消息。
2. 向用户个人频道发送通知事件。
3. 写入站内通知。
4. 已订阅 Web Push 时发送唤醒推送。
5. 单次任务完成；重复任务计算下一次执行时间。

调度器必须使用数据库任务状态防止同一任务重复执行。

### 4.5 用户反馈

创建成功：

```text
好哒，我记下啦：明天早上 8 点提醒你带伞。
```

无法解析：

```text
你想让我几点提醒呀？告诉我具体时间就行。
```

执行时：

```text
到时间啦！记得带伞哦～
```

## 5. 安全边界

- 只创建提醒消息，不执行提醒文本描述的真实动作。
- 提醒内容有长度限制。
- 每位用户最多保留固定数量的待执行任务。
- 不接受过去时间。
- 不在日志中记录完整提醒内容。
- 用户只能管理自己的任务。

## 6. 验收

- [ ] 明确说“记住……”后立即创建记忆。
- [ ] 自动记忆不再随机跳过。
- [ ] 保存失败不会开启成功冷却。
- [ ] 新记忆通过 Socket.IO 立即出现在前端运行时。
- [ ] 回答只注入优先级最高的 15 条记忆。
- [ ] `30 分钟后提醒我关火`直接创建单次任务。
- [ ] 每日和每周提醒能计算下一次执行时间。
- [ ] 模糊时间不会误建任务。
- [ ] 到期任务只执行一次，并创建消息、通知和推送。
- [ ] 服务重启后任务仍然存在。
