# 小多利角色文案优化设计

## 背景

小多利是 Pet10 的核心角色，本次基于用户补充的完整角色设定，对小程序端六个位置的界面文案进行重写，使文案更有趣、更有自述感。

## 角色设定（本次文案的事实依据）

- 被遗弃过的小狗，独一无二
- 外形有点像柯基，只是腿短，没人知道是什么品种
- 特别好吃，最喜欢蛋黄，看到鸡蛋黄会开口说话
- 最放松的睡姿是四脚朝天
- 主人一出门就趴在门口枕着主人的拖鞋睡；主人回家就叼着娃娃迎接
- 走到哪都是人气小狗，人见人爱，很喜欢笑
- 大部分时候老实巴交，莫名其妙的时候会皱着眉头斜眼看人
- 很粘人
- 产品规则：小多利只能养一只，需选择好一起养的对象

## 文案风格原则

1. **第一人称自述**：所有文案以小多利自己的口吻说话（关于弹窗、信件深情自述；互动反馈用短句口语）。
2. **零重复分工**：每个特征只在唯一位置出现，六个部分各讲一个侧面，互不重复。
3. **固定规范例外**：空状态分享按钮文案按项目规范固定为「邀请好友一起养一只小多利吧~」，不改。

|---|---|

| 四脚朝天睡姿 | 睡觉反馈 |
| 仅此一只、选择共养对象 | 选择对象流程 |

### 2. 小窝空状态信件（MiniappNestLetter.tsx）

开头保留「给还没来的家人：」，署名保留「—— 小多利」。

- 第一段：你好呀，我是小多利。我被遗弃过一次，所以比谁都懂被选中的珍贵。我有点粘人，但只要你愿意，我会一直一直在。
- 第二段：主人出门的时候，我会枕着她的拖鞋睡——那是我等她的方式。我的窝能装下两个人，你要不要邀请一位对你重要的人，来做另一个？从那天起，你们一起喂我、一起陪我玩。要是你们一起递来一颗鸡蛋黄，我会当场开口说谢谢。
- 第三段：初见那天，我会把它认真记成一条纪念。从那天起，门口等你们的，就是我。

## 变更范围与约束

- 仅修改 `miniapp/src` 下的文案字符串，不涉及功能逻辑、样式、图片。
- 涉及文件：`features/main/MiniappMeView.tsx`、`features/main/MiniappNestLetter.tsx`、`features/auth/MiniappLaunchLoading.tsx`、`features/auth/MiniappLoginScreen.tsx`、`pages/index/index.tsx`、`features/tarot/tarotReading.ts`，以及空状态邀请引导所在组件。
- 同步更新断言这些文案的测试（如 `miniappMainLayout.test.ts`、`miniappViewModel.test.ts`、`miniappPresentation.test.ts` 等）。
- 「选择一起养的对象」引导文案依附于现有邀请流程 UI，不新增页面；若现有 UI 无对应标题/说明位置，仅替换语义最接近的现有文案。
- 修改后按小程序规则清缓存重编译，提供预览验证。
