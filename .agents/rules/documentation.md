# Documentation Rules

Update the relevant document when a change affects:

- user-visible behavior;
- a feature flow or state transition;
- an API, environment variable, or deployment step;
- an animation timeline or visual acceptance point;
- an asset, image format, loading strategy, or size budget.

Feature documents are written in Chinese for non-technical maintainers. They must explain purpose, user flow, normal result, failure states, code entry points, risks, and an acceptance checklist.

Keep documents factual and link to existing repository paths. Do not copy large source files into documentation.
