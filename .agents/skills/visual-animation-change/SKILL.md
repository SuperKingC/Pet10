# Visual Animation Change

1. Read `.agents/rules/tarot-animation.md` when the feature is Tarot.
2. Read the relevant `docs/visual-baselines/` timeline and checkpoints.
3. Record the current branch, base commit, target stage, and non-goals.
4. Change one stage or one visual target only.
5. Run focused behavior tests.
6. Start `npm run review` and provide a direct stage URL when available.
7. Check fixed mobile and desktop viewports, reduced motion, rapid input, and console errors.
8. Do not merge or deploy until the user accepts the visual result.
