# Visual Animation Change

1. Read `.agents/rules/ui-presentation.md` and the relevant feature document under `docs/features/`.
2. Record the current branch, base commit, target page, and non-goals.
3. Change one page or one visual target only.
4. Run focused behavior tests.
5. Rebuild `miniapp/dist` and preview it in WeChat DevTools.
6. Check typical phone viewports, reduced motion, rapid input, and console errors.
7. Do not merge or deploy until the user accepts the visual result.
