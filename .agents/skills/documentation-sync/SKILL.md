# Documentation Sync

1. Identify which feature or operations document describes the changed behavior.
2. Update the purpose, flow, failure state, code entry point, risk, or acceptance checklist that changed.
3. Update diagrams and asset manifests when their inputs changed.
4. Run `npm run check:docs` and `npm run check:assets` when available.
5. Report the document paths changed.
